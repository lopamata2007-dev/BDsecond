### Требования к изображениям:
- Формат: PNG, JPG, JPEG
- Размер: любой (автоматически ресайзится до 48x48)
- Цвет: grayscale или RGB (конвертируется автоматически)
- Минимум 50-100 изображений на класс для качественного обучения

### Где взять данные:
1. **FER-2013**: https://www.kaggle.com/datasets/msambare/fer2013
   - Отфильтруйте только Happy, Sad, Neutral категории
2. **CK+**: http://www.pitt.edu/~emotion/ck-spread.htm
3. **Собственный датасет**: используйте скрипт для сбора через веб-камеру

## 4. Запуск обучения

```bash
cd /workspace
python src/train.py
```

### Параметры обучения (в src/config.py):
- `EPOCHS = 30` — количество эпох обучения
- `BATCH_SIZE = 32` — размер батча
- `EMOTIONS = ["Happy", "Sad", "Neutral"]` — список эмоций
- `NUM_CLASSES = 3` — автоматически вычисляется из списка

### Что происходит при обучении:
1. Загружаются изображения из `dataset/train/` и `dataset/test/`
2. Применяется аугментация данных (повороты, сдвиги, отражения)
3. Модель обучается 30 эпох с валидацией
4. Лучшая модель сохраняется в `models/emotion_model.keras`

## 5. Запуск инференса (веб-камера)

```bash
cd /workspace
python src/inference.py
```

### Клавиши управления:
- **q** — выход из программы
- **r** — сброс сглаживания предсказаний

### Оптимизации инференса:
1. **DETECTION_SCALE = 0.5** — детекция лиц на уменьшенном кадре (быстрее в 4 раза)
2. **PREDICT_INTERVAL = 5** — предсказание каждые 5 кадров (снижение нагрузки)
3. **SMOOTHING_FACTOR = 0.3** — сглаживание предсказаний (плавный вывод)

### Визуальный отклик:
- Цветная рамка вокруг лица (цвет зависит от эмоции)
- Текст с названием эмоции и процентом уверенности
- Гистограмма вероятностей для всех 3 эмоций
- Информация о FPS в углу экрана

## 6. Изменение списка эмоций

Для изменения набора эмоций:

1. Откройте `src/config.py`
2. Измените список `EMOTIONS`:
   ```python
   EMOTIONS = ["Happy", "Sad", "Neutral", "Angry"]  # 4 эмоции
   ```
3. `NUM_CLASSES` обновится автоматически
4. Переобучите модель: `python src/train.py`

# ТРОУБЛЕШУТИНГ

## Ошибка: "Модель не найдена"
**Решение:** Сначала запустите обучение: `python src/train.py`

## Ошибка: "Директория обучения не найдена"
**Решение:** Создайте структуру папок dataset/train/{Happy,Sad,Neutral}/

## Ошибка: "Не удалось открыть веб-камеру"
**Решение:** 
- Проверьте подключение камеры
- Закройте другие приложения, использующие камеру
- Попробуйте изменить индекс камеры: `cv2.VideoCapture(1)`

## Ошибка: "Expected 3 classes, found X"
**Решение:** Проверьте, что в dataset/train ровно 3 подпапки с названиями эмоций

## Низкая точность
**Решение:**
- Увеличьте количество обучающих изображений
- Добавьте больше аугментации в train.py
- Увеличьте количество эпох (EPOCHS в config.py)
