# ОТЧЁТ ПО ПРОЕКТУ: РАСПОЗНАВАНИЕ ЭМОЦИЙ (3 КЛАССА)

## 1. ВВЕДЕНИЕ

### 1.1 Цель проекта
Разработка системы распознавания эмоций по изображениям лиц с использованием методов глубокого обучения. Проект адаптирован для работы с **3 классами эмоций**: Happy (счастье), Sad (грусть), Neutral (нейтральное состояние).

### 1.2 Применяемые подходы
В проекте комплексно применены следующие подходы из требуемого списка:

| Подход | Реализация в проекте |
|--------|---------------------|
| **a. Рекуррентные нейронные сети** | BiLSTM (Bidirectional LSTM) для анализа последовательностей признаков |
| **b. Трансформеры и механизмы внимания** | Attention layer для выделения важных частей последовательности |

### 1.3 Архитектура решения
```
Входное изображение (48x48, grayscale)
         ↓
CNN блок (3 слоя Conv2D + MaxPooling)
         ↓
Reshape → последовательность (36, 128)
         ↓
BiLSTM (двунаправленный LSTM) ← RNN подход
         ↓
Attention Layer ← Механизм внимания
         ↓
Concatenate + Flatten + Dense
         ↓
Dropout (0.5)
         ↓
Dense(3, softmax) → [P(Happy), P(Sad), P(Neutral)]
```

## 4. СОЗДАНИЕ МОДЕЛИ

### 4.1 Архитектура модели (гибридная CNN + BiLSTM + Attention)

#### CNN Блок (извлечение пространственных признаков)
```python
Input: (48, 48, 1)
    ↓
Conv2D(32, 3x3, relu) + MaxPooling(2,2) → (24, 24, 32)
    ↓
Conv2D(64, 3x3, relu) + MaxPooling(2,2) → (12, 12, 64)
    ↓
Conv2D(128, 3x3, relu) + MaxPooling(2,2) → (6, 6, 128)
```

#### Преобразование для последовательной обработки
```python
Reshape: (6, 6, 128) → (36, 128)
# 36 "временных шагов" по 128 признаков каждый
```

#### BiLSTM Блок (рекуррентная сеть)
```python
Bidirectional(LSTM(64, return_sequences=True))
# Forward LSTM + Backward LSTM = 128 единиц
# Выход: (batch, 36, 128)
```

#### Attention Механизм (внимание)
```python
Attention()([recurrent, recurrent])
# Вычисляет веса важности для каждого временного шага
# Создаёт контекстный вектор
```

#### Классификатор (адаптирован для 3 классов!)
```python
Concatenate([recurrent, attention_output]) → (batch, 36, 256)
    ↓
Flatten → (batch, 9216)
    ↓
Dense(128, relu)
    ↓
Dropout(0.5)
    ↓
Dense(3, softmax)  ← АДАПТАЦИЯ: было Dense(7)
    ↓
Output: [P(Happy), P(Sad), P(Neutral)]
```

### 4.2 Компиляция модели
```python
model.compile(
    optimizer="adam",
    loss="categorical_crossentropy",
    metrics=["accuracy", "precision", "recall", "auc"]
)
```

### 4.3 Адаптация под 3 класса
| Компонент | Было (7 классов) | Стало (3 класса) |
|-----------|------------------|------------------|
| Финальный слой | Dense(7, softmax) | Dense(3, softmax) |
| Выход модели | (batch, 7) | (batch, 3) |
| Список эмоций | 7 эмоций | Happy, Sad, Neutral |
| NUM_CLASSES | 7 | 3 |

## 8. ИНТЕРПРЕТАЦИЯ РЕЗУЛЬТАТОВ

### 8.1 Анализ работы гибридной архитектуры

#### Почему CNN + BiLSTM + Attention?
1. **CNN** — эффективно извлекает пространственные признаки (края, текстуры, формы)
2. **BiLSTM** — анализирует контекстные зависимости между признаками
3. **Attention** — выделяет наиболее важные области для классификации

#### Преимущества подхода
- **Гибридность**: сочетание сильных сторон CNN и RNN
- **Интерпретируемость**: Attention веса показывают, на что смотрит модель
- **Эффективность**: 3 класса упрощают задачу и повышают точность

### 8.2 Ограничения
1. Требует достаточно большого датасета для обучения
2. Чувствительна к освещению и углу лица
3. Не работает с закрытым лицом (маска, очки с толстой оправой)

### 8.3 Возможности улучшения
1. Добавление большего количества данных
2. Использование предобученных моделей (transfer learning)
3. Расширение до 5-7 эмоций
4. Добавление мультимодальности (аудио + видео)
